# Go Learning

This repository is my personal journey of learning the Go programming language from basic to advanced concepts. The goal is to build strong fundamentals, practice with small examples, and gradually move toward real-world Go development.

## About

Go, also known as Golang, is a simple, fast, and powerful programming language created by Google. It is widely used for backend development, cloud services, command-line tools, APIs, distributed systems, and DevOps tools.

This repo will contain notes, code examples, practice programs, and mini projects as I learn Go step by step.

## How to Run Go Programs

Run a Go file:

```bash
go run filename.go
```

Build a Go program:

```bash
go build filename.go
```

Check the installed Go version:

```bash
go version
```

Initialize a Go module:

```bash
go mod init module-name
```
